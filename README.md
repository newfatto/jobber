# JOBBER

Программа для получения данных о работодателях и вакансиях с сайта [hh.ru](https://hh.ru), сохранения их в базу данных PostgreSQL и удобного взаимодействия через консольный интерфейс.

## Функциональность
- Получение информации о выбранных работодателях и их вакансиях через API hh.ru.
- Автоматическое создание базы данных и таблиц (`employers`, `vacancies`).
- Загрузка данных о работодателях и вакансиях в PostgreSQL.
- Класс `DBManager` для работы с БД:
  - список компаний и количество вакансий у каждой;
  - все вакансии с названием компании, вакансии, зарплатой и ссылкой;
  - средняя зарплата по вакансиям;
  - вакансии с зарплатой выше средней;
  - поиск вакансий по ключевому слову.
- Консольное меню для взаимодействия с пользователем.

## Установка
1. Склонируйте репозиторий:
```bash
   git clone https://github.com/username/jobber.git
   cd jobber
```
   
2. Установите зависимости:
```bash
    pip install -r requirements.txt
```
или
```bash
    poetry install
```
    

3. Создайте файл database.ini с параметрами подключения к PostgreSQL:
```bash
    [postgresql]
    host=localhost
    user=postgres
    password=yourpassword
    port=5432
```

## Использование

Запустите проект:
```bash
    python main.py
```

В консоли появится меню:
```bash
1 — Список компаний и число вакансий каждой компании
2 — Все вакансии
3 — Средняя зарплата
4 — Вакансии с зарплатой выше средней
5 — Поиск вакансий по ключевому слову
0 — Выход
```

## Настройки

Список отслеживаемых компаний и название создаваемой базы данных задаётся в файле [settings.py](src/settings.py)
:
```bash
company_list = [
    "0000",  # Компания 1
    "1111",  # Компания 2
    ...
]
database_name = "name"
```

## Внимание!
Данные берутся из публичного API hh.ru, поэтому при больших объёмах может действовать ограничение на число запросов: 1000 вакансий для одной компании.
